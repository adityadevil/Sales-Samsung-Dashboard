# Sales-Samsung-Dashboard
📱 Samsung Supply Chain & Logistics Dashboard | Power BI

📌 Project Overview

The Samsung Supply Chain & Logistics Dashboard is an interactive Power BI project designed to analyze and monitor the complete supply chain process. It provides a clear view of sales, suppliers, inventory, shipments, and customer performance through multiple interactive dashboards.

The dashboard helps businesses track key performance indicators (KPIs), identify operational issues, improve inventory management, monitor supplier performance, and support data-driven decision-making.

🎯 Project Objectives

Monitor overall supply chain performance.
Analyze sales and revenue trends.
Track supplier performance and product quality.
Optimize inventory levels and reduce defective stock.
Monitor shipment status and delivery performance.
Understand customer purchasing behavior.
Support faster and smarter business decisions.
